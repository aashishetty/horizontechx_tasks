# VYBE — Social Media Platform

A polished mini social-networking platform built for the Horizon TechX internship task.

## Required task features
- User profiles
- Posts and comments
- Like and follow system
- Frontend: HTML, CSS, JavaScript
- Backend: Express.js
- Database: MongoDB / Mongoose

## VYBE extras
- Explore / people discovery
- Trending posts
- Activity timeline
- Notification panel
- Profile editing + profile picture
- Image posts
- Feeling and location metadata
- Responsive premium UI
- Dark/light theme preference
- Follow/unfollow suggestions
- Toast feedback and polished interactions

## Run
1. `npm install`
2. Create/update `.env` with `MONGO_URI=...`
3. `node server.js`
4. Open `http://localhost:3000`

Demo account is created by the server when MongoDB is connected.
